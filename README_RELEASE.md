# Pentab v1.0.0 — Release Package

AndroidタブレットをPCの高精度ワイヤレスタッチパッド・ペンタブレットとして使用できるアプリパッケージです。

---

## 📦 パッケージ構成

- **`Pentab_server/`**: Windows用サーバーアプリケーション
  - `PentabServer.exe` (高速・軽量な単一バイナリ、タスクバーインジケーター常駐対応)
  - `Start_PentabServer.bat` (起動用バッチ)
  - `Resources/app.ico` (アプリアイコン)
- **`Pentab/`**: Androidタブレット用クライアント
  - `app/build/outputs/apk/debug/app-debug.apk` (Android 7.0以降対応 APK)

---

## 🚀 PCサーバーの起動と自動起動設定

1. **初回起動**:
   - `PentabServer.exe` を起動します。
   - 初回起動時、Windowsのファイアウォール警告が表示された場合は「アクセスを許可」してください。

2. **Windows起動時の自動起動 (Auto-Start)**:
   - アプリ画面左側の **「Windows起動時に自動起動 (Auto-Start)」** にチェックを入れると、次回PC起動時から自動的に起動します。
   - タスクトレイ（インジケーター）のアイコンを右クリックし、「Start with Windows」からも切り替え可能です。

3. **インジケーター（システムトレイ）常駐**:
   - **「起動時にトレイへ最小化 (Start in Tray)」** をONにすると、PC起動時に画面を邪魔せずインジケーター内で静かに常駐します。
   - ウィンドウ右上の [×] ボタンまたは [📥 Hide to Tray] ボタンを押すと、タスクバーから消えて通知領域（トレイ）に最小化されます。
   - トレイアイコンを **ダブルクリック** すると、いつでも設定ウィンドウを再表示できます。

---

## 📱 Androidアプリのインストール

1. APKをタブレットに転送してインストールします。
2. アプリを起動し、PCのIPアドレスまたは `127.0.0.1`（USB接続時）を入力して **Connect** をタップします。

## 🔌 接続方法

### 1. USB接続（超低遅延・推奨）
USBデバッグを有効にしてPCと接続し、PC側で以下のコマンドを実行します：
```bash
adb reverse tcp:8765 tcp:8765
```
タブレット側で `127.0.0.1` のまま「Connect」を押すと即座に接続されます。

### 2. Wi-Fi接続（ワイヤレス）
PCとタブレットを同じWi-Fiルーターに接続し、PCサーバー画面に表示されているWi-FiローカルIP（例: `192.168.1.xxx`）をタブレットに入力して「Connect」を押します。
